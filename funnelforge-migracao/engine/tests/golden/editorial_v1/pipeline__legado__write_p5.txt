Estes são os BLOCOS DE APOIO que deixam a página dinâmica, escaneável e "wow" — do jeito
que converte no funil de arbitragem. Copie o HTML EXATAMENTE (espaçamentos já calibrados),
troque só o [conteúdo]. Use MUITOS deles (não 2-3 — bastante), VARIADOS e DISTRIBUÍDOS ao

blocos ricos seguidos sem texto entre eles.

REGRAS DE OURO:
- 100% ESTÁTICOS: sem <script>, <button>, <iframe>, <form>. Os CTAs continuam sendo os
  wp:buttons/CTAs inline de sempre (destino único do funil). Estes blocos NÃO viram CTA.
- Número/valor/data/percentual SÓ pode vir da BASE FACTUAL. Sem dado real → não use "cards
  de número" nem "barra de progresso". Nunca invente cifra.
- Mobile-first: parágrafos curtos; um bloco de apoio por vez. Os blocos SUBSTITUEM texto
  denso — não somam parágrafos, deixam a leitura mais leve.
- VARIE de página para página: não use sempre os mesmos. Escolha conforme o conteúdo.
- Dentro de `wp:html`, NUNCA use `<p>` (nem com atributos): use `<div>`/`<span>`.
  Parágrafos só existem como blocos nativos `wp:paragraph`, fora do HTML bruto.
- PRIORIZE os blocos de maior impacto que quase ninguém usa e estão mais ABAIXO nesta lista:
  TABELA COMPARATIVA (wp:table), DUAS COLUNAS (wp:columns) e PULLQUOTE (wp:pullquote). Não caia
