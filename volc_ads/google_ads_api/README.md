# Referência Google Ads API v25

Corpus local de referência usado durante a construção do motor. Não é código de
runtime e pode envelhecer quando a API mudar de versão.

## Entrada

- `instalar_assistente_desenvolvedor.md` — orientação de uso do assistente;
- `api_reference_v25.md` — referência principal;
- `api_reports_overview_v25.md` — visão de reports;
- `api_codes_formats.md`, `structured_snippets.md` e `topics.md` — material complementar;
- `mcp_google_ads.md` e `assistant_for_devs_gads_api.md` — integração e apoio ao desenvolvimento.

Duplicatas exatas `api_v25.md` e `api_assistant_gads.md` foram removidas na onda
zero de higiene; o conteúdo permanece integralmente nos arquivos canônicos acima.
